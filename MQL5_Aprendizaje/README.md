# MQL5_Aprendizaje
Repositorio personal de aprendizaje de **MQL5**, el lenguaje de programación 
de MetaTrader 5. Aquí recopilo ejemplos básicos, ejercicios y estrategias 
sencillas para dominar el desarrollo de Expert Advisors (EA), indicadores 
y scripts.

## Contenido
- Fundamentos del lenguaje (variables, tipos, operadores)
- Estructuras de control (if, for, while, switch)
- Funciones y modularización
- Estrategias básicas (cruce de medias, compra/venta)
- Indicadores personalizados
- Utilidades y snippets reutilizables

## Objetivo
Documentar mi progreso y servir como referencia rápida para futuros proyectos.
